# Team-CRYPTICS
Team CRYPTICS Submission for the IIT Kanpur ISEA Innovation Challenge &amp; Bootcamp On Hardware Security co-located with CSAW'2026 (Cyber Security Awareness  Worldwide) Competition 

## Usage of the Script
Run the code using the standard python command from terminal. Keep in mind to edit the path variables which store the CSV input path and the output for the correlation matrix.
Ex: 'cd "to project directory, default Downloads'
    'python aes_CPA_analysis.py'

Note: To speed up the calculation process make the TRACE_STEP variable = 10000 or 1000 but to find min no. of traces you might need to run it with TRACE_STEP=1
